# 🌐 Acemins

## 📖 Descripción

Sitio web desarrollado para Acem ins con el objetivo de mejorar su presencia digital y ofrecer una plataforma moderna para presentar sus servicios e información corporativa.

---

## 🎯 Objetivos

- Modernizar la presencia digital de la empresa.
- Mejorar la experiencia de navegación.
- Implementar un diseño adaptable a dispositivos móviles.
- Facilitar el acceso a la información de la empresa.

---

## ✨ Funcionalidades

- Página de inicio.
- Información sobre la empresa.
- Servicios.
- Contacto.
- Diseño responsivo.

---

## 🛠 Tecnologías utilizadas

- React
- TypeScript
- Vite
- HTML5
- CSS3
- Netlify (Hosting)
